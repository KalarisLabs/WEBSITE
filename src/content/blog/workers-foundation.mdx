The Kalaris Labs website uses Astro's islands architecture and Cloudflare Workers Static Assets. Most pages are prerendered, while server routes such as the contact endpoint execute in the same Worker deployment.

This keeps the public surface small, preserves fast static delivery, and gives server features a clear path to grow without introducing a second hosting platform.
